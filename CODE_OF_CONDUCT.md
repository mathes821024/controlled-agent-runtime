# Code of Conduct

We pledge to make participation in this project respectful, welcoming, and free
from harassment. Be constructive, focus criticism on ideas and evidence, respect
privacy, and assume good intent while still examining safety claims rigorously.

Unacceptable behavior includes harassment, discriminatory language, threats,
doxxing, publishing private information, or knowingly bypassing project safety
controls. Report concerns privately using the process in [SECURITY.md](SECURITY.md)
when they involve security or sensitive information. Maintainers may edit, remove,
or reject contributions and may temporarily or permanently restrict participation
when necessary to protect the community.
